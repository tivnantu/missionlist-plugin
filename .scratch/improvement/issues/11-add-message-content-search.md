## What to build

添加消息内容搜索：在标题搜索基础上，支持搜索会话的消息内容。使用懒加载策略（不预缓存所有内容），搜索时按需读取 `messages/*.json` 文件。

**端到端行为**：
- 搜索框输入 → 先过滤标题匹配项（实时）
- 若无标题匹配或用户选择"搜索内容" → 懒加载消息内容并匹配
- 匹配结果高亮显示（标题 + 匹配的消息片段）
- 缓存当前搜索结果（搜索会话内有效）

**决策来源**：
- PRD Decision 9（消息内容搜索：懒加载，不预缓存）
- User Story #21

## Acceptance criteria

- [ ] 支持搜索消息内容（不仅是标题）
- [ ] 使用懒加载策略（不预缓存所有内容）
- [ ] 搜索时按需读取 `messages/*.json` 文件
- [ ] 匹配结果高亮显示（标题 + 匹配的消息片段）
- [ ] 缓存当前搜索结果（搜索会话内有效）
