# ADR-0001: 自定义右键菜单实现方式

日期: 2026-05-18
状态: 已接受

## 上下文

需要为会话列表添加右键菜单，包含：打开会话 / 重命名 / 收藏 / 导出到 Markdown / 删除。

实现选项：
- **方案 A**：使用浏览器原生 `contextmenu` 事件 + `event.preventDefault()`
- **方案 B**：自定义 DIV 覆盖层（绝对定位在光标位置）
- **方案 C**：使用 VS Code `showQuickPick`（命令面板风格）

## 决策

**采用方案 B：自定义 DIV 覆盖层**

## 后果

**优点**：
- 菜单出现在光标位置（标准桌面应用行为）
- 可以使用 VS Code 主题变量（`var(--vscode-xxx)`）实现无缝集成
- 可以完全自定义菜单项布局和交互

**缺点**：
- 需要手动处理点击外部关闭、Esc 关闭、焦点管理
- 需要自己实现键盘导航（方向键）

**风险**：
- 自定义菜单可能与 VS Code 原生主题不完全匹配（使用 CSS 变量可以最小化此风险）

## 替代方案

- 方案 A（原生 contextmenu）：样式难以自定义，无法使用 VS Code 主题
- 方案 C（showQuickPick）：交互模式不同（在屏幕中央显示，不符合右键菜单直觉）
