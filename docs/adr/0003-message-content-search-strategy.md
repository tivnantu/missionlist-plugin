# ADR-0003: 消息内容搜索策略

日期: 2026-05-18
状态: 已接受

## 上下文

需要支持搜索会话的消息内容（不仅是标题）。实现选项：

- **方案 A**：预缓存所有消息内容（启动时一次性加载到内存）
- **方案 B**：懒加载策略（搜索时按需读取 `messages/*.json` 文件）
- **方案 C**：使用全文搜索引擎（如 SQLite FTS，但增加复杂度）

## 决策

**采用方案 B：懒加载策略**

- 搜索标题（实时，已在 Phase 1 实现）
- 搜索内容时，按需读取 `messages/*.json` 文件
- 缓存当前搜索结果（仅本次搜索会话有效）
- 不预缓存所有消息内容（避免内存占用过高）

## 后果

**优点**：
- 内存占用低（不预缓存所有消息）
- 搜索响应快（仅读取匹配会话的消息文件）
- 实现简单（无需引入额外依赖）

**缺点**：
- 首次搜索某个会话时需要读取文件（IO 开销）
- 缓存仅本次搜索有效（切换搜索词后需重新读取）

**风险**：
- 会话非常多时，搜索所有会话的消息内容可能较慢
- 需要设计缓存策略（避免重复读取文件）

## 替代方案

- 方案 A（预缓存）：内存占用过高（特别是消息历史很长时）
- 方案 C（全文搜索）：实现复杂，当前阶段不必要
